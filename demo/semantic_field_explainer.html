open-kgo · Layer 2

SemanticField

Schema-grounded, continuous, multi-hop entity scoring — grounded in DC electrical circuit theory. Layer 1 says valid or invalid. Layer 2 says how much.

01

What it is

SemanticField sits between your KG connector and your application. You pass it a subgraph and a query expressed as two anchor nodes — a source (who or what you're searching from) and a sink (the category or target you want to reach). It returns a ranked list of entities scored by how much signal flows through them. 

# incoming query → SemanticField → ranked results

scores = SemanticField.compute_and(
    namespace = "metaqa",
    edges     = subgraph_edges,          # 2-hop neighbourhood of anchors
    source    = {"Nolan": 1.0},      # WHO   ← high voltage
    sink      = {"Sci-Fi": 0.0},    # WHAT  ← ground
)
# → {"Interstellar": 0.394, "Inception": 0.312, "Dark Knight": 0.0, ...}
ParameterRole
sourceHigh-voltage anchor — the "who" or "from" side
sinkLow-voltage anchor — the "what" or category side
edgesSubgraph — typically 2-hop neighbourhood of both anchors
namespaceOntology namespace — looks up relationship weights from Layer 1

The subgraph is not the full KG — it's the 2-hop neighbourhood around your anchors. This keeps the solver tractable and the results focused. Unknown relationships default to G=1.0 (open-world assumption).

02

1-hop, 2-hop, and multi-hop

SemanticField doesn't know about hop count — it sees a graph and solves it. The shape of your query determines what depth you need.

1-hop — single relationship

"Which actors has Nolan worked with?" — one step from director to actor via movies.

SemanticField.compute(
    namespace="metaqa",
    edges=one_hop_edges,          # Movie → starred_actors → Actor
    anchors={"Nolan": 1.0},
    relation_type="starred_actors",
)

Actors directly connected to Nolan's films score above zero. Everything else scores 0.

2-hop — the standard AND query

"Sci-Fi films by Nolan." — director → movie → genre. The movie sits between two anchors.

SemanticField.compute_and(
    namespace="metaqa",
    edges=two_hop_edges,          # Director→Movie→Genre
    source={"Nolan": 1.0},
    sink={"Sci-Fi": 0.0},
)

Current flows through a movie only if it connects both anchors. Dark Knight connects to Nolan but Action is a dead end — no path to Sci-Fi ground, zero current, excluded automatically.

Multi-hop — drug repurposing

"Which drugs, via their protein targets and pathways, are candidates for Alzheimer's?"

# 3-hop path:
# Drug → binds → Protein → involved_in → Pathway → associated_with → Disease

SemanticField.compute_and(
    namespace="biokg",
    edges=subgraph,               # 2-hop neighbourhood of Drug + Disease anchors
    source={"Metformin": 1.0, "Aspirin": 1.0},
    sink={"Alzheimer's": 0.0},
)

Drugs with partial pathway overlap still score above zero. Partial satisfaction is built into the physics — no thresholding, no binary cutoff. A drug with a weak pathway connection scores lower than one with a strong direct hit, in proportion to the conductance (ontology weight) of each relationship.

This is the gap no existing tool fills: SPARQL is schema-grounded but binary. Vector search is continuous but schema-free. SemanticField is both — typed edges with weights, continuous scores, partial satisfaction.

03

Why electromagnetism

We evaluated several physics frameworks before committing to DC circuits. The requirement: it must map naturally onto typed, weighted knowledge graphs and support both schema grounding and continuous scoring simultaneously.

FrameworkWhat it modelsWhy we passed
Thermodynamics / diffusion Spreading, heat flow, equilibration Maps to random walks — no natural AND semantics, no voltage/current duality
Quantum mechanics Superposition, interference, probability amplitudes No intuitive analogy for "a query"; requires complex amplitudes
Fluid dynamics Flow through networks, Reynolds number Close, but EM has richer theory for discrete graphs; conductance cleaner than viscosity
DC electrical circuits Voltage sources, resistors, current, Kirchhoff's laws Maps perfectly onto typed weighted KGs ✓

Why DC circuits fit

1. Ontology weights are conductances. A high-weight relationship (directed_by = 0.9) is a low-resistance wire — signal passes easily. A weak relationship (has_tags = 0.2) resists signal. The ontology literally is the impedance map of the graph.

2. Query anchors are voltage sources. Fixing voltage at anchor nodes is the standard impressed-voltage treatment in electrical network theory (Strang, Introduction to Linear Algebra, ch. 10). No approximation — this is the exact analytical solution.

3. AND is free. In a series circuit, current only flows if both ends are connected. Dark Knight connects to Nolan but Action is a dead end — no path to ground, voltage floats to 1.0, zero potential difference, zero current. The physics enforces the AND constraint with no extra logic.

4. Partial satisfaction is built in. A drug with a weak pathway connection scores lower than one with a strong direct hit — in proportion to G. No thresholding, no binary cutoff.

5. Well-understood math. Graph Laplacian, Kirchhoff's current law, Gaussian elimination. Every step is traceable and explainable to an engineer with a circuits background.

Every step is grounded in established electrical network theory — Kirchhoff's current law, graph Laplacian, Dirichlet boundary conditions. Nothing exotic, everything traceable.

05

The math

Step 1 — Graph Laplacian

Build the conductance-weighted Laplacian L from all edges:

L[i][i]  =  Σ G(i,j)   # sum of conductances at node i
L[i][j]  = -G(i,j)    # negative conductance between i and j

Step 2 — Dirichlet boundary conditions

Partition nodes into boundary B (anchors, fixed voltage) and interior I (unknown). Solve the reduced system:

L_II · V_I  =  −L_IB · V_B

Gaussian elimination with partial pivoting. Disconnected nodes receive V=0.

Step 3 — Score by current

After solving, score each interior entity by the current it carries:

I(e) = Σ  G(e,j) × (V(j) − V(e))
        j : V(j) > V(e)

Why current and not voltage? Voltage alone doesn't enforce the AND constraint — an entity close to the source gets a high voltage regardless of whether it connects to the sink. Current is zero unless both a high-voltage and a low-voltage neighbour exist.

07

The three layers

Layer 1 — OntologyRegistry built

YAML-declared per domain. Relationship types, valid domain/range pairs, and weights. Weights flow into Layer 2 as conductances.

relationships:
  directed_by: { domain: Movie, range: Person, weight: 0.9 }
  has_genre:   { domain: Movie, range: Genre,  weight: 0.7 }
  has_tags:    { domain: Movie, range: Tag,    weight: 0.2 }

Layer 2 — SemanticField built

DC circuit model. Subgraph + query anchors → ranked entity scores. Implemented in open_kgo/feature_groups/kg/ontology/semantic_field.py. Numba-accelerated, pure-Python fallback when numba not available.

Layer 3 — Discovery Engine planned

Will use Layer 2 field values to guide multi-hop traversal toward a goal type — a beam search that follows the current. Highest-scoring paths first. This is what turns SemanticField into an autonomous knowledge graph explorer.
